# مِنار | MINAR

منصة جهاز خدمة ذاتية ذكية تهدف إلى تحسين تجربة ضيوف الرحمن من خلال تقديم خدمات الإرشاد، الترجمة، البلاغات، الدعم الصحي، والمعلومات الميدانية باستخدام تقنيات الذكاء الاصطناعي.

## فكرة المشروع

مِنار هو نموذج تجريبي لجهاز خدمة ذاتية ذكي يُوضع في المواقع الميدانية مثل منى، مزدلفة والمسجد الحرام، ويساعد ضيوف الرحمن على الوصول إلى المعلومات والخدمات بسهولة، مع دعم مختلف اللغات واحتياجات ذوي الإعاقة.

## الخدمات الرئيسية

- المساعد الذكي متعدد اللغات.
- الخرائط التفاعلية والإرشاد إلى المواقع.
- معرفة أقرب الخدمات والمرافق.
- تقديم البلاغات ومتابعتها.
- الإرشادات الصحية والإسعافات الأولية.
- المحتوى الديني المعتمد.
- دعم ذوي الإعاقة.
- تسجيل الدخول عن طريق التعرف على الوجه أو قراءة الجواز.
- استخدام النظام كضيف دون تسجيل الدخول.
- لوحة تحكم للجهات المختصة.

## مسار المستخدم

1. تظهر شاشة ترحيبية تحمل اسم مِنار.
2. يختار المستخدم لغته أو يكتبها أو يتحدث بها.
3. ينتقل إلى شاشة تسجيل الدخول.
4. يمكنه الدخول عن طريق:
   - التعرف على الوجه.
   - قراءة جواز السفر أو بطاقة نسك.
   - المتابعة كضيف.
5. تظهر الصفحة الرئيسية والخدمات المتاحة.
6. عند تسجيل الدخول يظهر ترحيب باسم المستخدم.
7. يستطيع المستخدم تسجيل الخروج بعد الانتهاء.
8. في حال عدم استخدام الشاشة لمدة 30 ثانية يظهر تنبيه قبل تسجيل الخروج تلقائيًا.
